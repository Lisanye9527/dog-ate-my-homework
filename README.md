# The Dog Ate My Homework: Funniest Excuse

A [make.fun](https://make.fun) bounty entry. A deterministic Python program
writes one line — the funniest excuse a dog can give, in the dog's own voice,
after being caught eating the homework — to `/output/entry.txt`.

Run it:

```
python3 main.py
```

The output directory defaults to `/output` and can be overridden with the
`MAKEFUN_OUTPUT_DIR` environment variable. The program self-checks the
competition gate (UTF-8, 1–200 characters, single line) before writing and
verifies the written file by reading it back.
